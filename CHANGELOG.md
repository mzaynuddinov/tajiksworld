# Changelog

## 1.0.0

- Initial release of the TajiksWorld theme.
- Visual builder for the homepage, header, footer, and individual pages, with draft, publish, undo, redo, device preview, library sections, and JSON import/export.
- News flags, views, reading time, galleries, video, and custom types for video, galleries, podcasts, interviews, and special reports.
- Advertisement manager, newsletter subscribers, theme settings, and SEO tags that yield to Yoast SEO and Rank Math.
- Tajik, Russian, and English interface translations. Polylang and WPML compatibility for article languages.
