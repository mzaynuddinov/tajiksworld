# Development and build

The theme runs without Composer or Node. PHP classes load through `app/autoload.php`. Production CSS and JavaScript are already in `assets/`.

## Frontend assets

Source of truth:

- `resources/css/theme.css` — editorial CSS and Tailwind directives
- `resources/js/theme.js` — front-end behavior
- `resources/js/builder.js` — visual builder
- `resources/js/admin.js` — media picker

```bash
npm install
npm run build
```

`npm run build` writes minified `assets/css/theme.css` and copies plus minifies the scripts into `assets/js/`. WordPress loads the `.min.js` files unless `SCRIPT_DEBUG` is true.

## Translations

`bin/i18n-map.json` holds Russian (`ru`) and Tajik (`tg`) strings. `npm run i18n` regenerates:

- `languages/tajiksworld.pot`
- `languages/tajiksworld-ru_RU.po` and `.mo`
- `languages/tajiksworld-tg_TJ.po` and `.mo`

WordPress loads `tajiksworld-{locale}.mo` from `languages/`.

## Composer

`composer.json` maps `TajiksWorld\` to `app/` for tooling. The theme does not require `vendor/` at runtime.

```bash
composer dump-autoload
```

## Tests that do not need WordPress

```bash
php tests/run.php
npm test
```

`tests/run.php` checks layout sanitizing, default homepage sections, and renderer escaping. `npm test` checks JavaScript syntax, the builder escape map, built assets, and a static security scan.

## Screenshot

`screenshot.png` is a 1200×900 editorial preview generated by `php bin/screenshot.php`. It is the file WordPress shows on the Themes screen. It is not a photograph of a live site.
