# Tajiks World

HTML + Tailwind prototype for [tajiksworld.com](https://tajiksworld.com/) — news for Tajiks worldwide.

## Open

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8765
```

## Languages

| Code | Language | Direction |
|------|----------|-----------|
| `tg` | Тоҷикӣ | LTR |
| `fa` | فارسی | RTL |
| `ru` | Русский | LTR |
| `en` | English | LTR |

- `/` Tajik
- `/fa/` Persian (RTL)
- `/ru/` Russian
- `/en/` English
